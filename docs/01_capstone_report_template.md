# Capstone Report Template

## 1. Problem Statement
Describe the local student-support assistant use case, the need for reproducible local inference, and the benefit of comparing prompt strategies and models without relying on closed hosted APIs.

## 2. Dataset Source
Explain the dataset used for evaluation, why it fits the support domain, and how it was prepared for prompting and comparison.

## 3. Model Comparison
Summarize the open-source models compared in the project, including expected trade-offs in quality, latency, size, and hardware fit.

## 4. Selection Justification with Scoring
Show the evaluation criteria and justify the final model choice using measurable evidence such as response quality, latency, and consistency notes.

## 5. Demo Results
Present the live demonstration results from the app, including the selected model, prompt style, sample questions, and observed output.

## 6. Limitations and Future Work
Discuss current limitations, including lightweight evaluation, heuristic scoring, and hardware dependency, and suggest how the system could be improved in future iterations.

## 7. Documentation of Prompts used
Provide the prompt templates and examples used during testing, including zero-shot, few-shot, and chain-of-thought variants.
